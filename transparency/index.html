Rules

Launch fee
none
Trading fee on the curve
0.9% of every buy and sell
Launch window
buys pay 99% in the launch block and the next one, then the normal fee; the creator’s dev buy, inside the launch, pays the normal fee
Protocol share of fees
15%; the rest goes to each coin’s payees, fixed at launch
Graduation
when 793.1M tokens are sold (100K SOL raised); 1% graduation fee; the pool’s seed liquidity is locked forever
After graduation
the coin trades in its own Ekubo pool, which only Hokori’s locker can open, holding the curve’s reserve as liquidity nobody can withdraw (Ekubo’s own contracts can be upgraded by Ekubo’s governance); the same 0.9% fee on every trade, its SOL side to the fee vault like the curve’s fees and its coin side burned
Coin supply
999.99M tokens, minted once; no owner, no minting, no pause

Who can change what

Nobody. None of the launchpad’s contracts has an owner, an admin, a pause or an upgrade entry point, so the code at each address stays the code deployed there. The factory launches a coin for whoever calls it. A coin’s curve answers to no one. The locker takes a graduation only from that coin’s own curve and pool callbacks only from Ekubo’s core, and has no withdrawal. The fee vault registers a coin’s payees only from the factory, and each payee claims only their own share; Hokori’s treasury is one more payee, at the share above. What Hokori can do is launch new factories, which changes nothing for the coins already launched.
